# Calculadora Criptografica

Calculadora para la materia de Criptografia (aritmetica modular, n = 27 por defecto).

- Matrices kxk: producto, producto mod n, determinante, gcd(det mod n, n) e inversa mod n.
- Conversion binario a decimal y decimal a binario, con procedimiento.
- XOR de binarios.

## Version Java (Swing)

```
cd java
javac *.java
java CalculadoraCripto
```

## Version web

Abrir `web/index.html` en cualquier navegador (`cripto.js` debe estar en la misma carpeta).

## Entrada rapida de matrices

Escribir los valores por filas separadas con `;`, por ejemplo `2 5 7; 1 3 4; 6 1 9`.
